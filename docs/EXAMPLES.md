# Neutral examples

This distribution includes reusable templates and tools, not production recordings or client-project records. Any historical measurement mentioned in a tool is engineering context, not a claim that a new user's environment has passed acceptance.

For a first project, use a solid-color test clip, a short original script, the neutral brand profile, and generated tones. Write the brief and acceptance checks before rendering. Keep source media and all output in a separate project directory.

The music-promo kit is in `skills/style-music-promo/assets/kit/`. Its placeholder media and brand inputs must be supplied locally. The app-capture driver is a pattern, not a ready-to-run test against an installed demo app; replace bundle identifiers and UI selectors for your own application.

The website's animated timeline is synthetic HTML/CSS. It is explicitly labeled as an illustration and contains no personal footage, recordings, screenshots, or voice data.
