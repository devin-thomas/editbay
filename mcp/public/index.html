Setup prompt

Install the EditBay plugin in Claude Code: run claude plugin marketplace add devin-thomas/editbay, then claude plugin install editbay@editbay. When both succeed, tell me to start a new session. In that session, load the video-director skill and use it to plan my edit. Keep my footage and renders on this machine.
