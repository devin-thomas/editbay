# Scene library (brand-neutral)

| Scene | What it shows | In / out | Notes |
|---|---|---|---|
| Motif entrance | the motif arrives with physics (drop, squash, settle, blink) | from nothing / stretches or multiplies | 1 bar; the only thing on screen |
| Kinetic statement | a 3-5 word line from the brand's voice, each word with its own treatment | motif becomes a cursor or underline / words break into marks | one accent word in the accent voice |
| Shape field | the motif multiplied into a grid that pulses on the beat, a wave rolling through | marks gather into the grid / grid tilts into perspective | density peak candidate |
| Diagram | an easing curve, a timeline, a waveform, a chart drawn in time | a line from the previous scene / the line becomes an edge of the next | shows thinking, not decoration |
| Interface | a real fragment of the subject: code building, a terminal, a card assembling | the grid snaps into UI blocks / the frame zooms through | never a fake product screen |
| Material | a solid form with light (CSS 3D transforms, gradients) turning | the interface folds into an object / a flash | keep it seek-safe: no physics engines |
| Field | particles or a texture field with a seeded generator | the object dissolves / condenses into the motif | skip when the brand forbids particles |
| Flurry | half-beat cards, one per earlier chapter, recapping its material | hard cuts on half-beats / clears to the lockup | 6-8 cards, the densest stretch |
| Lockup | the wordmark builds, the motif lands in it, one quiet line | from the flurry / hold to the end | the sparsest frame, held 1.5-2.5 s |
