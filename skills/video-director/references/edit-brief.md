# EDIT.md template

```markdown
# EDIT: <title>

- Goal: <what the viewer should know or feel afterwards, in one sentence>
- Audience: <who, and what they already know>
- Sources: <files, URLs, folders; for URLs, who owns them>
- Deliverables: <variants and profiles, e.g. 16:9 explainer profile + 9:16 shorts>
- Brand: <brand profile id>   Style: <style skill or none>
- Voice: <none | stock voice | creator clone (consent: where/when)>   Disclosure: <line and placement>
- Mode: <collaborative | autonomous>; beats <strict | open>
- Beats the creator asked for: <"when I say X, show Y, there, because Z" lines>
- Sourcing allowed: <captures, official assets, stock, local generation, paid generation (estimate required)>
- Proof: <what the piece must show on screen to back its claims>
- Human boundaries: <spend, sign-ins, voice likeness, publishing, final taste>
- Route and machines: <skill chain; GPU host for ASR/TTS/downloads; local renders>
- Goal condition: <see goal-conditions.md>
```

## Anatomy of a request that edits well

Single-prompt edits that worked carry the same ten things. Keep the creator's own words where they give them; the
examples below are for a setup tutorial.
1. **The source and the tool**: "`raw/take-03.mov`, built in HyperFrames".
2. **A style in a few words**, plus a reference if there is one: "calm and editorial, lots of empty space".
3. **The order of work**: "transcript first, then the plan; build after I approve the plan".
4. **Beats tied to speech and to a place on screen**: "when I name the command, type it out on the right half".
5. **Legibility**: "any text over footage sits on a solid or frosted card".
6. **Emphasis**: "as I list the three steps, add one word each in the lower third".
7. **Sourcing permissions**: "screen-record the docs page; no generated images of real people".
8. **The point**: "a beginner can repeat the setup from the video alone".
9. **The face**: "keep my face clear".
10. **Verification**: "check the frames after every change and show me the sheet".

A request that is mostly feelings still works when the brief turns each feeling into one of these lines.
